Fokus revisi
------------
Perbaikan tampilan pada:

  SYSTEM SETTINGS -> INTERSECTION LAYOUT

Perubahan
---------
1. Panel pengaturan kiri sekarang mempunyai scroll vertikal sendiri.
2. Panel Live Preview kanan sekarang mempunyai scroll vertikal sendiri.
3. Scroll horizontal dimatikan supaya susunan dua kolom tetap stabil.
4. Ukuran minimum Live Preview diubah dari 380 x 380 menjadi 300 x 300.
   Diagram tetap digambar dengan rasio persegi dan dapat membesar ketika ruang
   layar mencukupi.
5. Tombol tindakan tidak lagi dipaksa berada dalam satu baris:

     Baris 1 : RELOAD FROM CONTROLLER
     Baris 2 : RESET SG POSITIONS | SAVE INTERSECTION LAYOUT

6. Field Signal Group Identification dibuat lebih ringkas agar 12 nama SG tidak
   terlalu banyak menggunakan ruang vertikal.
7. Tidak ada perubahan pada format data, API ESP32-S3, revision guard,
   konfigurasi traffic, atau traffic runtime.

- Menu tidak saling menimpa.
- Diagram Live Preview terlihat utuh.
- Pada layar pendek, bagian yang tidak muat dapat digulir tanpa menggeser panel
  di sebelahnya.
